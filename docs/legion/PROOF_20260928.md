   corroborated tier-A properties. The fix ranks tier first, then
   `legion_priority`.
2. **Unlock map.** Every source-less gap collapsed into one `UNSOURCED` row
   (6,487), hiding which signal was missing, and paid sources were unlabelled.
   Gaps are now `UNSOURCED:<signal_id>`, and each row is labelled
   `NO_SOURCE_REGISTERED` / `PAID_FOUNDER_GATE` / `FREE_OR_PUBLIC`.

   after changing the profile deduped onto the sealed v1.0 job and served the
   old brief. `profile_version` is now a job param, and a mismatch raises
   `LEGION_SPEC_DRIFT`.
